# Sehyun Choi — Portfolio

Personal academic and research portfolio, built with Astro 7, TypeScript, and Markdown. The site is statically generated and published to GitHub Pages at [syncdoth.github.io](https://syncdoth.github.io/).

## Edit the site content

Most writing lives in a small set of clearly named files:

- **Profile, social links, research interests, and navigation:** [`src/data/site.ts`](src/data/site.ts)
- **Work history, education, and news:** [`src/data/timeline.ts`](src/data/timeline.ts)
- **Publication records:** [`src/data/publications.ts`](src/data/publications.ts)
- **Projects and their detail pages:** one Markdown file per project in [`src/content/projects/`](src/content/projects/); unpublished write-ups are kept in [`src/content/projects/archive/`](src/content/projects/archive/)
- **Blog posts:** one Markdown file per post in [`src/content/blog/`](src/content/blog/)
- **Coursework page:** [`src/content/pages/courseworks.md`](src/content/pages/courseworks.md)
- **Images and downloadable files:** [`public/assets/`](public/assets/)

Project and blog frontmatter is checked against schemas in [`src/content.config.ts`](src/content.config.ts). Add a Markdown file with the same frontmatter fields as its neighbors; Astro creates the page and listing entry automatically.

See [`CONTENT.md`](CONTENT.md) for exact templates and guidance on adding a post, project, or record.

## Run locally

Use Node.js 24 (or Node.js 22.12 and newer) and npm:

```sh
npm install
npm run dev
```

Build the static site to `dist/` with `npm run build`, then preview that output with `npm run preview`.

## Publish

The GitHub Actions workflow builds the site and deploys it to GitHub Pages when changes reach `master` or `main`. Pull requests build the site without publishing it. The repository is named `syncdoth.github.io`, so Astro serves the site from the domain root and keeps the current URL.

If GitHub Pages is still configured to deploy from a branch, set **Settings → Pages → Build and deployment → Source** to **GitHub Actions** once. After that, pushes to the default branch publish automatically.

## Project structure

```text
src/
  components/      Shared interface pieces
  content/         Blog posts, project write-ups, coursework
  data/            Profile and portfolio records to edit
  layouts/         Shared page shell
  pages/           Routes generated by Astro
  styles/          Site-wide visual system
public/assets/     Static images, PDFs, and other files
.github/workflows/ Build and GitHub Pages deployment
```
